## Custom Application Integration

For custom applications, we provide comprehensive SDKs and REST APIs.

<CodeGroup tabs="JavaScript,Python,Java">
  ```javascript
// JavaScript SDK Example
const { NCERTClient } = require('ncert-docs-sdk');

const client = new NCERTClient({
  apiKey: 'your-api-key',
  baseUrl: 'https://api.ncert-docs.com'
});

// Ask a question
const answer = await client.askQuestion({
  textbookId: 'math-class-10',
  chapter: 5,
  question: 'Solve quadratic equation x² + 5x + 6 = 0'
});

console.log(answer);
```
  ```python
from ncert_docs_sdk import NCERTClient

client = NCERTClient(
    api_key='your-api-key',
    base_url='https://api.ncert-docs.com'
)

# Ask a question
answer = client.ask_question(
    textbook_id='math-class-10',
    chapter=5,
    question='Solve quadratic equation x² + 5x + 6 = 0'
)

print(answer)
```
  ```java
import com.ncertdocs.sdk.NCERTClient;

NCERTClient client = new NCERTClient.Builder()
    .apiKey("your-api-key")
    .baseUrl("https://api.ncert-docs.com")
    .build();

// Ask a question
String answer = client.askQuestion(
    "math-class-10",
    5,
    "Solve quadratic equation x² + 5x + 6 = 0"
);

System.out.println(answer);
```
</CodeGroup>

## Webhook Integrations

Set up webhooks to receive real-time notifications about student interactions.

<Expandable title="Webhook Configuration" default-open="false">
  Configure webhook endpoints in your dashboard to receive events like conversation starts, completions, and error notifications.
</Expandable>

### Webhook Events

| Event Type | Description | Payload |
|------------|-------------|---------|
| conversation.started | New conversation initiated | User ID, textbook info |
| conversation.completed | Conversation finished | Full conversation data |
| error.occurred | API error encountered | Error details |
| usage.threshold | Usage limit approached | Current usage stats |

<ExpandableGroup>
  <Expandable title="Webhook Security" default-open="false">
    All webhook requests include signature headers for verification. Always validate webhook signatures to ensure authenticity.
  </Expandable>
  <Expandable title="Retry Logic" default-open="false">
    Implement retry logic for failed webhook deliveries and handle duplicate events gracefully.
  </Expandable>
</ExpandableGroup>
