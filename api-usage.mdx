### Conversation Request Example

<CodeGroup show-lines="true" tabs={[]}>
  ```javascript
  const conversationRequest = {
  textbook_id: 'physics-class-12',
  chapter: 3,
  question: 'Explain electromagnetic induction',
  context: 'Include examples from daily life'
  };

  fetch('/api/v1/conversations', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer YOUR_API_KEY'
  },
  body: JSON.stringify(conversationRequest)
  })
  .then(response => response.json())
  .then(data => console.log(data.answer));
  ```

  ```python
  import requests

  conversation_data = {
    "textbook_id": "physics-class-12",
    "chapter": 3,
    "question": "Explain electromagnetic induction",
    "context": "Include examples from daily life"
  }

  response = requests.post(
    '/api/v1/conversations',
    json=conversation_data,
    headers={'Authorization': 'Bearer YOUR_API_KEY'}
  )

  print(response.json()['answer'])
  ```

  ```bash
  curl -X POST "/api/v1/conversations" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "textbook_id": "physics-class-12",
    "chapter": 3,
    "question": "Explain electromagnetic induction",
    "context": "Include examples from daily life"
  }'
  ```
</CodeGroup>

## Search Functionality

Search across multiple textbooks for specific topics or keywords.

Use specific keywords and subject terms for better search results.

### Search Parameters

| Parameter | Type   | Description            | Required |
| --------- | ------ | ---------------------- | -------- |
| query     | string | Search keywords        | Yes      |
| subjects  | array  | Filter by subjects     | No       |
| classes   | array  | Filter by class levels | No       |
| limit     | number | Max results to return  | No       |

### Common Error Codes

| Status Code | Description       | Action                  |
| ----------- | ----------------- | ----------------------- |
| 400         | Bad Request       | Check request format    |
| 401         | Unauthorized      | Verify API key          |
| 403         | Forbidden         | Check permissions       |
| 404         | Not Found         | Verify resource exists  |
| 429         | Too Many Requests | Implement rate limiting |
| 500         | Internal Error    | Retry with backoff      |
