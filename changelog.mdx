## Release History

<Update label="2024-10-15" description="v2.1.0" tags={["feature", "improvement"]}>

## New Features

- Added multi-language support for Hindi, Bengali, and Tamil textbooks
- Introduced batch processing API for bulk question handling
- Enhanced analytics dashboard with learning insights
- Added webhook notifications for conversation events

## Improvements

- Improved AI response accuracy for mathematics and science questions
- Reduced API response times by 30% through optimization
- Enhanced error messages with more detailed troubleshooting information
- Updated documentation with comprehensive integration guides

</Update>

<Update label="2024-09-20" description="v2.0.0" tags={["feature", "breaking"]}>

## New Features

- Complete API redesign with RESTful architecture
- Introduced OAuth 2.0 authentication alongside API keys
- Added support for custom model training
- Launched Moodle and Canvas integration plugins

## Breaking Changes

- API endpoints changed from `/v1/` to `/api/v1/` prefix
- Authentication headers now require `Bearer` prefix
- Response format updated to include metadata fields
- Deprecated old SDK versions (upgrade required)

</Update>

<Update label="2024-08-10" description="v1.5.0" tags={["feature", "bugfix"]}>

## New Features

- Added conversation history and context retention
- Introduced usage analytics and reporting
- Added support for diagram and image-based questions
- Launched mobile SDK for iOS and Android

## Bug Fixes

- Fixed encoding issues with special characters in textbooks
- Resolved authentication timeout problems
- Corrected chapter numbering in physics textbooks
- Fixed search results pagination

</Update>
